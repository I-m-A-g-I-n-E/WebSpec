# URL Grammar

Defines the URL structure, object type system, resolution chain,
and formal grammar that underpin every WebSpec request. These
documents specify how natural-language intent maps to concrete
URL paths.

> **Status:** This section describes the REST-hierarchy URL grammar, which is **Proposed (C)**.
> The gateway shipping today routes by subdomain + literal MCP tool name. See the
